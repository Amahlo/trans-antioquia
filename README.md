# Trans-Antioquia - Sistema de Gestión de Servicios de Transporte

Aplicación web interna diseñada para **Trans-Antioquia** para digitalizar y centralizar la captura, rastreo y gestión de solicitudes de transporte de personas y mercancías. El sistema reemplaza los registros en papel y permite auditar las operaciones realizadas por los colaboradores de la empresa.

---

## 📌 Contexto del Proyecto

* **Cliente / Owner:** Jaime Zapata
* **Sede Principal:** Barrio Antioquia, Medellín, Colombia
* **Tipo de Aplicación:** Herramienta interna / Captura e historial de solicitudes
* **Usuarios:** Reducido a 8 colaboradores internos (acceso completo para el equipo)
* **Alcance Operativo:** Servicios de transporte nacional e internacional 24/7 (personas, carga y servicios combinados)

---

## 🚀 Características Principales

1. **Captura de Solicitudes:** Formulario interno e interfaz simple para solicitar servicios de transporte tanto para personas como para encomiendas.
2. **Rastreo por Colaborador:** Registro obligatorio por usuario (8 colaboradores) para identificar qué agente creó o gestionó cada negocio.
3. **Contador de Servicios:** Métricas básicas e historial en vivo de servicios registrados.
4. **Tarifario Variable:** Cálculo/registro basado en la distancia del trayecto.
5. **Soporte Multi-idioma:** Interfaz preparada para atender requerimientos en múltiples idiomas.
6. **Diseño Responsive:** Adaptado para dispositivos móviles, tablets y escritorio.

---

## 🎨 Guía de Estilo y UI/UX

* **Enfoque:** Interfaz minimalista, limpia e intuitiva.
* **Paleta de Colores:** Tonalidades frías (Azules `#1E3A8A` / `#2563EB`, Grises `#1F2937` / `#F3F4F6`).
* **Tipografía:** `JetBrains Mono` / `JetBrains Sans`.
* **Identidad:** Logotipo de logística de transporte simple e imágenes sencillas.

---

## 🛠️ Especificaciones Técnicas

* **Usuarios Internos:** 8 cuentas con permisos completos de gestión.
* **Persistencia:** Base de Datos para almacenamiento de registros e historial de servicios.
* **Manejo de Tiempos:** Tiempos de entrega/atención gestionados internamente de forma manual por cada cliente.
